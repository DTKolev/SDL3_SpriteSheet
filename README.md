# Sprite Sheet Project

### Description:
This is a small project that I developed when learning SDL3. It showcases a 2D character's animations sourced from an example sprite sheet.

### Navigation
When the program is launched, it opens a small borderless window that you can navigate with keyboard input (the system doesn't take mouse input)
- 'Esc' - close the window
- 'Q' - run animation
- 'W' - attack animation 01
- 'E' - attack animation 02
- 'R' - attack animation 03
- 'T' - attack combo animation (goes to idle animation when finished)
- 'U' - jump animation (goes to run animation when finished)
- 'Space' - idle animation
